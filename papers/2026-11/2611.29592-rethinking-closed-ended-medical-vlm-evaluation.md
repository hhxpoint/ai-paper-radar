# Rethinking Closed-Ended Medical VLM Evaluation: From Stable Wrongness to Counterfactual Answer Sensitivity

> **arXiv**：[2611.29592](https://arxiv.org/abs/2611.29592) · **主题**：`多模态与视觉` · **发表**：2026-11-22 · **发表状态**：arXiv 预印本
> **作者**：Qi Wu、Xiaoyu Liu、Ao Wang、Rongsheng Wang、Wenting Chen、Wenxuan Wang、Qingsong Yao · [PDF](https://arxiv.org/pdf/2611.29592) · [HTML](https://arxiv.org/html/2611.29592)  
> 状态：每日精读（智能体）

## 一句话结论
医学闭式 VQA 存在“稳定地错”：去掉、黑掉或换成无关图像后，模型的 yes/no 答案仍有约 57–62% 与真图一致，且置信度不降反升（随机图 0.901 > 真图 0.871）；据此提出的 CAS（反事实证据敏感性）在 7 个 VLM × 3 个数据集共 21 个设置上，错误检测宏平均 AUROC 比最好的 HAC 家族高 0.150（0.736 vs 0.586）。

## 为什么值得读（观点）
它攻击的是近两年很吃香的“采样一致性/语义熵”不确定性估计的前提：不一致才有信息。若错误本身来自稳定捷径，高一致性恰恰会掩盖错误。对任何做置信度、拒答、选择性预测的人，这是必须知道的盲区。

## 问题与动机
医学 VLM 走向临床决策支持时，“什么时候能信”比平均准确率更关键；闭式 yes/no 便宜可自动评分，但二值答案空间会让语言先验、prompt 模板、输入格式主导决策。21 个模型-数据集设置平均的探针结果：真图 acc 0.762 / conf 0.871 / yes 率 0.487；纯文本 0.544 / 0.790 / 一致 60.4%；黑图 0.540 / 0.794 / 一致 57.3%；随机图 0.560 / **0.901** / 一致 61.9%。也就是说，拿掉患者特异的视觉证据，模型不会变谨慎，只是 yes 率被输入状态整体挪走（0.487→0.304/0.294）。

## 方法与关键洞察
固定干预空间 C = {text-only, black, noise, blur}，对每个样本记录 commit 答案 ŷ 的对数概率变化，抽出四类信号：target-support shift a、相对 opposite 答案的 margin shift b、干预下对 ŷ 的原始概率 u、硬预测是否保持 r；用 mean/max/min 聚合，得到 9 维 φ = [T_full(a) ‖ T_full(b) ‖ T_sub(u) ‖ E_c(r)]，再用五折分层交叉验证、类别平衡的 L2 逻辑回归映射成风险分。洞察是：可测的不是“答案稳不稳”，而是“答案是否被真图唯一支撑”；消融显示单独最有用的信号是对手答案的决策边界位移（0.711 AUROC），而不是硬预测稳定性（0.538，接近随机）——后者恰是 HAC 类方法的隐含假设。

## 证据与实验
21 个设置全部优于 HAC/HAC-Platt/HAC-Gate，宏平均 AUROC 0.586→0.736，AURC 0.222→0.131、E-AURC 0.183→0.092（两者都取 HAC 家族最好的 HAC-Gate），Cov@10% 0.179→0.496。四象限分析最关键：HAC 低风险但 CAS 高风险的那组，HAC 风险 0.121 与 H-low/C-low 的 0.128 几乎相同，但错误率是 0.318 vs 0.111——CAS 把 HAC 最信任区域里的隐藏错误挑了出来（CAS 风险 0.603 vs 0.229）。在 HAC 最低风险 20% 里，错/对的 HAC 风险几乎相同（0.091 vs 0.095），CAS 则给出 0.545 vs 0.348。17 维全特征只比 9 维多 0.005 AUROC。

## 可质疑之处
①“稳定错误”的比例被三值一致率口径放大：纯文本条件下模型本该答“不知道”，却被强制二选一，60% 一致里有多少是真无视图像、多少是 yes/no 先验被输入格式拉动，无法区分；而作者自己发现黑图会把 yes 率从 0.487 压到 0.304，说明 a、b 特征部分在测“图的统计量”而非“证据使用”。②黑图/噪声/模糊不是干净的因果干预，它们引入新的分布外线索，作者在 Limitations 里承认。③风险模型为每个设置单独拟合五折逻辑回归，AUROC 增益里有多少来自 9 维特征、多少来自“逐设置拟合”，缺少 train-on-A/test-on-B 的跨设置迁移实验。④只有 yes/no，开放式医学 VQA 不可用，作者主动限定。⑤样本量小（VQA-Med-2019 每格仅 64 题），多个格子置信区间跨 0（如 Qwen3-VL-2B +0.072 [−0.023,+0.170]），宏平均 +0.150 由少数大增益格子拉动。

## 与我的研究关联
病理语音/医学语音多模态模型同样会出现“不看输入也能猜对”的捷径（例如靠说话人、设备或问题模板）。这套探针成本极低（四次额外前向），可以直接做成 ASR/TTS 评测里的 grounding 检查或拒答门控：答案在输入被破坏后仍高置信 → 判为可疑。做 agent 的话，它与今天第 2 篇 AOVO 的反事实探针可以共用一套实现。

## 摘要原文

<summary>展开英文摘要</summary>

As medical VLMs are increasingly evaluated for clinical decision-support scenarios, knowing when to trust their predictions is critical. Closed-ended medical VQA has become a common benchmark format because it enables automated scoring. Yet, systematic investigation into whether this format changes the reliability problem remains scarce. We identify a failure mode that we call stable wrongness: models can produce incorrect yes/no answers that remain confident and repeatable even when patient-specific visual evidence is removed or mismatched. This failure violates the premise behind sampling-stability uncertainty methods, including recent hallucination-aware calibration (HAC) variants: disagreement is informative only when errors are unstable. When shortcut-driven errors are themselves stable, sampling agreement can remain deceptively high. Motivated by this limitation, we introduce Counterfactual Answer Sensitivity (CAS), which shifts reliability estimation from answer stability to evidence sensitivity. CAS uses cross-modal counterfactual interventions, such as text-only, black, and corrupted images, to audit whether a committed yes/no answer remains supported when visual evidence is invalidated. Across 7 VLMs and 3 benchmarks, CAS outperforms the best HAC-family scores across all evaluated settings, achieving a macro-averaged AUROC gain of +0.150 for error detection. Mechanistic analysis further shows that CAS recovers hidden errors in the HAC-confident region and that its strongest standalone signal is counterfactual decision-boundary shift rather than hard prediction stability. Our findings suggest that closed-ended evaluation should test visual dependence, not only answer stability, in safety-critical medical contexts.
