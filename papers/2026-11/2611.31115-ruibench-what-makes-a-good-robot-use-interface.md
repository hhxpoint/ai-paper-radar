# RUIBench: What Makes a Good Robot-Use Interface?

> **arXiv**：[2611.31115](https://arxiv.org/abs/2611.31115) · **主题**：`大模型与推理` · **发表**：2026-11-23 · **发表状态**：arXiv 预印本

## 一句话结论
只改"机器人使用接口"（RUI）而不换模型，Claude Code 在 30 个操作任务上的平均成功率从 45.3% 升到 80.7%，是 Claude Code 与 Codex 平均差距（2.1 点）的近 17 倍；小模型微调后同族接口也能从零样本 1.9% 到 27.3%，单接口最高 46.7%。

## 为什么值得读（观点）
它把通常被当成工程细节的"动作原语 + 控制权何时交还"定义成可测变量，并给出一个反常识结论：更强的抽象不一定更好。程序化执行在仿真里让 Claude Code 提升 10.7 点，到了真机上反而输给逐动作接口（36.0% vs 42.0%），说明"压缩决策"与"保留纠错反馈"是两件事，后者在物理不确定性下更值钱。

## 问题与动机
现有 embodied benchmark 固定接口比模型，接口研究又只比较单个设计选择，于是"接口到底贡献多少"没人量化。作者把 RUI 拆成动作抽象（关节/增量/步长/末端位姿/图像点/语义技能）与交互形式（每回复一个动作 vs 写 Python 程序）两轴，任务覆盖世界知识、上下文学习、发现、动态交互、接触丰富五类能力，每任务 15 个开发 mission + 20 个测试 mission。

## 方法与关键洞察
6×2=12 个固定接口，外加让 agent 自由选择的 RUI-Free，共享同一套 24 个工具、感知与评分器，只变 RUI。协议刻意去特权化：只给 RGB-D 与机器人状态、推理时环境继续演化（每次回复固定 8 秒延迟）、成功由离线轨迹独立判定且不告诉 agent。核心机制假设是 execution fragmentation：每个微小动作都要一次模型决策，会把清晰计划切碎并放大错误；有效接口应当减少不必要的决策，同时保住能让下一步改变的反馈。

## 证据与实验
仿真每个 agent 1,950 个 episode。Claude Code 45.3%（Step）→80.7%（Free），Codex 70.1→80.7；程序形式把 Claude 的平均成功率从 64.0% 提到 75.0%、中位轮数 30→12、单集成本 $1.40→$0.77，但 Codex 平均每个程序只包 0.9 个动作，只涨 2.7 点。小模型零样本 1.9%，微调后 Pose 46.7%、Skill 41.3%，Joint/Delta 只有 12.7–21.3%。650 个真机 episode（5 任务×5 layout×13 接口×2 agent）里程序优势消失，Free 从仿真 100% 掉到 44%。另有验证缺口：82.1%（Claude）与 70.9%（Codex）的失败 episode 以"宣称完成"结束，而这些失败在最终帧里 70–81% 可被独立判官看出。

## 可质疑之处
①换接口时工具名、提示与返回格式一起变了，"接口"与"提示工程"没有分离，45→81 里有多少来自语义命名无法归因。②真机只覆盖 5 个任务、单臂、每任务 5 个 layout，且 Free 接口 100→44 的崩塌恰恰说明仿真里选出的最优接口过拟合了仿真的零噪声与固定延迟；用它论证"真机改变偏好"样本太薄。③接触丰富任务（插显卡、叠衣）在几乎所有接口下都失败，无法区分是接口设计问题还是 2 cm 错位只占 8 像素的感知极限。④小模型 LoRA 的训练集含 30% Qwen3.8-Max 成功轨迹，比较的其实是"可学习性"而非接口本身。⑤离线判官识别虚假完成的比例（70.2%/80.9%）来自 23 个任务的子集，且判官与 agent 同源模型，存在相关性偏差。

## 与我的研究关联
对 agent 方向最可直接搬的是把"动作粒度/控制权交还"当超参而不是实现细节，以及"决策数—成功率—成本"三元汇报。语音侧的多工具 agent（边说边检索、TTS 前端调用音频工具）同样会遇到 execution fragmentation：一次回复只允许一个工具调用，往往比允许写小段编排更差。验证缺口一节对所有"agent 自报完成"的系统都是警告：动作级 post-condition 检查只把虚假完成从 87.5% 压到 81.2%，32 次自动重试只救回 2 次抓取，任务级 verifier 不能由动作级检查替代。

## 摘要原文

<details>
<summary>展开英文摘要</summary>

Foundation models can reason about complex physical tasks, yet translating this intelligence into reliable robot execution remains challenging. We argue that a critical, often overlooked factor is the robot-use interface (RUI), which determines how agents express and execute physical actions. To systematically study its impact, we introduce RUIBench, comprising 30 manipulation tasks across five suites spanning world knowledge, in-context learning, discovery, dynamic interaction, and contact-rich manipulation. We further develop RUIKit, a unified framework that crosses six action abstractions with two interaction forms, yielding 13 interfaces under shared perception and control. In simulation, changing only the RUI shifts a frontier agent's success rate from 45% to 81%, and that of a fine-tuned 4B model from 13% to 47%. Our analysis reveals that effective interfaces reduce unnecessary decisions while preserving essential feedback, with their benefits shaped by agent behavior and physical uncertainty. We further uncover a verification gap, where agents frequently declare success despite observable failures, revealing the need for task-level verification beyond individual actions. Together, these findings establish RUI design as a critical factor in embodied agent reliability.
